# DABBIR customer journey simplification v1

## Goal
Keep every current capability while reducing the owner's daily cognitive load.

## Primary daily navigation
- Today
- Conversations
- Appointments
- Customers
- Needs you
- Settings / More

## Advanced tools remain available
- Reports / analytics
- Automations
- Channels & integrations
- Notifications
- Help
- Team

## First-use principles
- Business setup remains one step: business name + type.
- No long setup form is introduced.
- Quick actions are surfaced on the dashboard.
- Empty states explain the next useful action.
- Technical runtime terminology is removed from the primary experience while operational truth remains available in advanced areas.

## Safety
- No API, Supabase schema, RLS policy, billing, WhatsApp authorization, or operational backend behavior is changed by this UI layer.
- Existing screens are preserved and moved behind progressive disclosure rather than deleted.
