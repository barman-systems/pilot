# Customer journey acceptance checklist

- [ ] New owner can understand the app without learning technical terms.
- [ ] Primary navigation shows daily work first.
- [ ] Advanced capabilities remain discoverable under More.
- [ ] Dashboard exposes direct actions for conversation, appointment, customers, and WhatsApp setup when needed.
- [ ] Empty states tell the owner what to do next.
- [ ] Business setup requires only name and type.
- [ ] Arabic labels are clear and owner-oriented.
- [ ] Mobile keeps five primary destinations.
- [ ] No backend/API/RLS behavior changes.
- [ ] Existing product screens remain present for regression compatibility.
