# S07 — تعديل المالك v0.3: تحقق داخلي

قرار المالك الصريح في هذه الجلسة: «الغ هذا الدور الغبي»، إشارة إلى دور جهة التشغيل المستقلة.

يسري هذا التعديل على مسار S07 الحالي ويستبدل اشتراط الجهة المستقلة في الترتيبات السابقة. تحفظ v0.2 والأدلة السابقة كسجل تاريخي دون إعادة كتابتها.

- أُلغي طلب تعيين جهة مستقلة وحيازتها الحصرية للمفاتيح والجفة معها كشرط لهذا المسار.
- التثبيت الخارجي وشهادة الاستقلال ليسا شرط قبول للاختبار الداخلي؛ لا تدعي النتائج استقلالًا أو مقاومة الرجوع الشامل بواسطة فريق التنفيذ.
- يتولى فريق التنفيذ التجهيز والتشغيل والتوقيع الداخلي وحفظ الأدلة. يبيّن التقرير هوية المنفذ وبصمات البناء والإعداد والمدخلات ونتائج كل ذراع وفشله.
- تثبت التوقعات والسياسات والنطاق قبل الجولة؛ يبقى الحفظ قبل التسليم والتحقق من سلامة الأدلة واختبار الاستعادة مطلوبًا.
- لا يحول إلغاء الدور النواقص الفنية إلى نجاح. الحالة التشغيلية: INTERNAL_PREPARATION_INCOMPLETE بدل التعطيل بسبب غياب الجهة.
- لا يمنح هذا التعديل تجاوز بوابات أمان المستودع أو الدمج أو النشر، ولا يغير Production أو v1. لا تشغيل لتجربة ناقصة الإعداد.

B1–B4 ملغاة كمتطلبات للمسار الداخلي؛ ليست ناجحة ولا منجزة. الأعداد والنتائج السابقة تحتفظ بتوصيفها الأصلي. الناتج المقبل تقرير تحقق داخلي، وليس شهادة مستقلة.
