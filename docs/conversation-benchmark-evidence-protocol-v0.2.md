تحل محل القالب الحواري السابق. سبب الإصدار: ضبط الإسناد التاريخي، منشأ الحالة، العمى، التغطية والتسجيل المسبق.
هذا المستند مستقل عن oracle-v1 وfixtures/v1. أي تعديل معياري لاحق يصدر في ملف بإصدار جديد مع سبب التغيير؛ لا يعاد تحرير v0.2 لإخفاء التاريخ.

## 1. قرارات ثابتة وحدود الإثبات

- كتلة المرشحين الحالية W03=6، W02=2. هذان مصدران موثقان في المراجعة، لا شهادة باكتمال تأهيل كل حالة.
- N يحسب حالات الفشل المؤهلة بعد إزالة التكرار؛ الضوابط الإيجابية خارجه. لكل مصدر n<=0.4*N. السقف لا يثبت استقلالًا إحصائيًا أو تمثيلية الإنتاج.
- مع 6/2 يلزم مصدران إضافيان على الأقل؛ 6/2/4/3 مثال حسابي فقط. بعد دمج سببي مثبت تعاد المعادلة بالكتل الفعلية، دون هدف مسبق لخفض W03.
- الشروط الثلاثة مفتوحة: استقلال المنشأ والحصص، تأهيل/دمج الجذور، جاهزية الاختبار.
- V3 التاريخي: BLOCKED_NO_RETRIEVAL_PATH، تعليق بانتظار مسار أرشفة مثبت، لا إغلاق أو نفي وجود نسخة في مكان آخر. إعادة التوليد ليست استرجاعًا. لا يعاد البحث نفسه دون دليل جديد.

## 2. سجل الواقعة وحلقة النقل

لكل توقيع: مرجع محمي للواقعة، توقع محدد، انحراف، فرضيات آليات، دليل مؤيد ومعارض، قرار مع تعليله.
لكل رسالة لازمة للمقطع، ولكل محاولة معالجة أو توليد/إرسال مرتبطة بها، سجل مستقل:

| الحقل | المطلوب |
| --- | --- |
| message_ref / attempt_ref | معرفات مراجعة مستعارة؛ الربط الأصلي في مخزن محمي خارج Git |
| evidence_ref | مرجع إيصال/سجل، hash، زمن الالتقاط، نوع الدليل وحدود معناه |
| received_at / processing_started_at / ended_at | أزمنة UTC منفصلة؛ زمن وصول الرسالة ليس زمن المعالجة |
| deployment_id / commit_sha | نشر المحاولة الفعلي وcommit كامل؛ null إذا لم يثبت |
| code_path / blob_hash / symbol | موضع الآلية في commit التاريخي |
| execution_link | رابط trace للرسالة/الدفعة والمحاولة والنشر؛ قرار engine/routing/config المؤثر |
| state_input | الحالة السابقة والمدخل، المرجع/hash ونوع المصدر |
| state_provenance | RAW_SNAPSHOT / RECONSTRUCTED / UNKNOWN |
| reconstruction | طريقة الاستنتاج، الافتراضات والبدائل والثقة مع تعليلها؛ لا نسبة رقمية مختلقة |
| result | PROVEN / CANDIDATE / REJECTED، مع سبب قابل للمراجعة |

الرسائل المركبة عبر نشرين، بما فيها S07، لا ترث deployment موحدًا. الرسالة التي تعاد محاولتها قد ترتبط بأكثر من نشر. إيصال التسليم لا يثبت نشر التوليد؛ يُربطان بدليل منفصل. تحفظ البيانات الوصفية الآمنة فقط في Git؛ لا نصوص عملاء أو إحداثيات أو أسرار أو معرفات محادثات أصلية.

فحص قابل للأتمتة: اكتمال الحقول، صحة hashes، وجود blob في commit، تطابق deployment مع commit، صلاحية ترتيب الأزمنة وربط المعرفات والمحاولات. وجود الكود والتقارب الزمني وحدهما لا يثبتان تنفيذه. هذا وصف لعقد الفحص؛ لا يوجد في هذا الإصدار مدقق آلي منفذ لهذه الخريطة.

غياب دليل لازم => CANDIDATE مع unresolved reason؛ دليل يناقض الإسناد => REJECTED لذلك الإسناد، لا محو الواقعة.
PROVEN للحلقة يتطلب ربط التنفيذ الفعلي؛ PROVEN للجذر يتطلب أيضًا إثباتًا سببيًا، لا مجرد نجاح فحص الحقول.

## 3. إعادة الإنتاج والدمج

إعادة الإنتاج التاريخية تستخدم commit النشر الفعلي مع runtime/dependencies/config والعقود/البيانات المؤثرة المطابقة أو المحددة بدقة. تستخدم نسخة معزولة بلا وصول Production أو إرسال خارجي.
أي اختلاف في البيئة يسجل وأثره يبرر؛ التشغيل على HEAD وحده لا يثبت سبب الواقعة التاريخية.
الحالة المعاد بناؤها من الرسائل تظل RECONSTRUCTED ولو أعادت نفس العرض. يمكن استخدام دليل تاريخي مكافئ بدل إعادة التشغيل، مع بيان ما يثبت وما لا يثبت.
لا تنقل آليات #729 إلى توقيع W03 دون حلقة نقل. لكل دمج: المظاهر، الآلية المشتركة، دليل عدم الاستقلال السببي، والسبب في إبقاء assertions مختلفة أو دمجها. تعدد assertions لا يضيف تغطية جذر مستقلة تلقائيًا.

## 4. وحدة المصدر والعمى

تسجل قبل التأليف سلسلة المنشأ: هوية المصمم، لقطة المدخلات وإصدارها، وجلسات التأليف وعلاقات المشاركة.
مصمم واحد بجلستين لا ينشئ مصدرين. اختلاف لقطة المدخلات أو المصمم وحده ليس شهادة استقلال؛ تسجل المواد والأشخاص المشتركون وتجمع السلاسل المترابطة تحفظيًا حتى تراجع.
قبل إتاحة العقد: تثبت هوية المصمم وإقرار اطلاعه السابق بتاريخ سابق لأول وصول/تأليف. لا وصول إلى W02/W03 أو نقاش #753 أو التواقيع أو اختبارات مشتقة منها.
الإقرار وسجلات الوصول ضمانان محدودان داخل البيئة؛ لا يثبتان عدم اطلاع خارجها. يفضل مصمم خارجي معزول، وتعلن المخاطر المتبقية. إذا تعذر إثبات العمى لا يوصف التأليف بأنه أعمى ولا يمنح تأهيلًا تلقائيًا.
معد هذه المواصفة مطلع على الوقائع، فلا يُعد مصممًا أعمى.

## 5. قرار العقد قبل التأليف

حزمة التسليم تسجل العقد الكامل ومصدره ونسخته وhash وسبب اختيار النسخة وأصل تعديلاتها، وتختم قبل الاشتقاق.
يحدد غرض واحد مسبقًا:
- CONTRACT_CONFORMANCE: عقد حالي/مصلح؛ النتائج دليل التزام بالعقد، وليست وحدها تغطية مستقلة لأنماط ما قبل الإصلاح.
- HISTORICAL_FAILURE_COVERAGE: نسخة سابقة موثقة مع سبب الاختيار ومدخلات مستقلة؛ القدم وحده لا يثبت الاستقلال.
لا ينتقى العقد أو أمثلته لإعادة تصنيع الوقائع. لا تبدأ الحزمة الفعلية قبل حسم الغرض والنسخة؛ v0.2 يجمد البروتوكول ولا يدعي تجميد لقطة عقد لم تُجمع بعد.

## 6. معيار التغطية المسبق

المعيار ثابت قبل الاشتقاق: 100% من الأزواج الممكنة بين عوامل (فئة الحقل، الانتقال العقدي، نوع الرسالة)، مع تغطية كل انتقال مسموح مرة على الأقل. الزوج المستحيل يحتاج قيدًا ومرجعًا في العقد؛ لا يستبعد بسبب صعوبة التنفيذ أو نتيجة الاختبار.
تقسم قيم الحقول إلى فئات تكافؤ وحدود موثقة من العقد؛ لا تستخدم ألفاظ الوقائع.
حد التسلسل L=عدد الحالات المجردة في مخطط العقد المجمد +1 انتقال. هذا حد منهجي معلن لا ادعاء بتغطية كل الدورات أو التاريخ غير المحدود. إذا ألزم العقد حدًا أطول فلا تُستثنى الحالة بصمت: يوقف الاشتقاق وتصدر مراجعة بروتوكول قبل التأليف.
إذا لم يكن تعداد الحالات/الانتقالات/أنواع الرسائل ممكنًا من العقد، الحالة BLOCKED_CONTRACT_INCOMPLETE.
المولد أو المصمم يسجل جميع الأزواج، القيود، التسلسلات المختارة ومرجع تغطية كل زوج. ترتيب المعرفات lexicographic وفك تعادل الاختيارات به يثبتان قبل التشغيل.
إذا تعذر استكمال التغطية أو الميزانية، النتيجة INCOMPLETE؛ لا تخفض النسبة بعد رؤية ما توفر. pairwise لا يثبت تغطية تفاعلات أعلى رتبة.

## 7. التسجيل المسبق والمحاولات

قبل أي تشغيل: يسجل السيناريو والحالة الابتدائية والتوقع وإصدار العقد والغرض ومواصفة التشغيل.
الختم: SHA256 لبايتات JSON canonical تضم scenario وexpected وregistered_at وبقية المواصفة. مفاتيح مرتبة recursively، arrays محفوظة، UTF-8 بلا pretty print، لا قيم غير محددة/غير منتهية.
يحفظ digest لدى أمين/نظام مستقل عن سيطرة المؤلف مع إيصال زمن خادم يسبق التشغيل، ومرجع سجل غير قابل للاستبدال الصامت. الزمن المكتوب ذاتيًا أو hash داخل ملف قابل للتعديل لا يكفي. التعديلات سجل جديد supersedes يحفظ الأصل ويستلزم تسجيلًا جديدًا قبل التشغيل.
إن لم يتوفر هذا المرجع: BLOCKED_PREREGISTRATION_ANCHOR؛ لا ادعاء تسجيل مسبق سليم.
المحاولتان الأساسيتان تطابقان المدخل والحالة الابتدائية وcommit والاعتماديات وmodel/provider/settings والseed إن دعم؛ تعاد تهيئة الحالة بينهما. تحفظ جميع النتائج والاختلافات، بما فيها إخفاق المزود. تطابق الإعداد لا يضمن حتمية النموذج.
محاولة حساسية ثالثة اختيارية تعلن مسبقًا المتغير الوحيد المعدل والسؤال الذي تختبره؛ لا تخلط بنتائج قابلية الإعادة أو تستخدم بديلًا لمحاولة فاشلة.
بعد التأليف: تدقيق اتساق المنشأ والإقرار والتوقيت، ثم مقارنة الانحراف بالتوقع، ثم فحص الجذر والحصص. الاصطدام غير المتوقع وحده ليس إثبات فشل أو استقلال.
